# a11y-ui

An accessible React component library built to **WCAG 2.2**, in TypeScript and Tailwind, where accessibility is part of each component's contract and is **checked by tests on every pull request**.

## What makes it different

- **Accessibility is tested, not claimed.** Each component has axe-core scans and keyboard and screen-reader-semantics tests (Testing Library). A regression fails the pull request.
- **Before and after remediation.** The *Remediation* section shows five defects common on e-commerce sites, their fix in code, the WCAG criteria involved, and what an automated scan does and does not catch.
- **Themes without CSS.** Every token is a CSS variable. Switch the theme in the toolbar above (the paintbrush): the default terracotta theme, and the *clairoki* theme made for the Clairoki site.
- **Honest limits.** Screen-reader announcements follow the ARIA specification; they have not yet been verified by hand with VoiceOver or NVDA.
